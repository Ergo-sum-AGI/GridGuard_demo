What the demo brings:
Four hardcoded scenarios, fully self-contained, no backend needed for the demo:

- Iberian Blackout (Spain, April 28 2025) - rapid cascade, ~15 GW lost, 60 million people. GridGuard raises the alarm 4–5 minutes before collapse.
- European Cascade (UCTE 2006) - oscillating frequency signature of zone splitting across 3 asynchronous islands. The oscillation pattern is visible in the chart - that's the fingerprint the algorithm recognizes.
- Dunkelflaute (Czech/EU projection) - slow inexorable decline without inertia; the scenario that could happen next winter. Full narrative about retired coal plants, no spinning reserve.
- Texas Polar Vortex (Uri 2021) - 60 Hz, load-shedding "staircase" steps visible in the chart, countdown to the 4m37s moment ERCOT nearly lost the grid permanently.

New features: animated alert banner escalates through ELEVATED → HIGH → SEVERE → CRITICAL with plain-English messages and recommended operator actions at each stage. Blackout overlay with "this was preventable" message showing how many minutes of warning GridGuard provided.

CSV drag-and-drop + paste input. Speed controls (1×/2×/5×/10×). Frequency line color changes with severity. RoCoF is now large and prominently colored. The threshold guide bar makes it instantly legible to anyone what the zones mean.
